# Borozdov Memoir

A theme from the Borozdov collection. Two faces — light **Heirloom**, a warm parchment
memoir, and dark **Fireside**, the same pages read by the fire. Sepia ink, a light
calligraphic serif, a chestnut button with a peach glow and ember sparks for what matters.

![Borozdov Memoir in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/memoir/main/screenshots/light.png)

![Borozdov Memoir in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/memoir/main/screenshots/dark.png)

## Principles

- **Sepia, never black.** Warm parchment paper, sepia ink and a soft cream for the side
  panels.
- **A light calligraphic serif.** Memoir Serif, from Gentium Plus, for the title, the three
  largest headings, callout titles and pull quotes; the smallest heading is an ember eyebrow
  in tracked capitals.
- **Chestnut with a peach glow.** Chestnut is the only fill: the main button, which glows
  peach from behind, a checked task and the toggle; the peach also washes the plain note and
  the highlighter.
- **Ember sparks.** Links, the caret and quote rules in ember, kept small.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- A chestnut main button with a peach glow behind it
- Callouts as white cards with a serif title; the plain note glows peach
- Pull quotes in the serif, a size up, beside an ember rule
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Ember**. Install Borozdov Ember under Settings → Appearance → Themes → Manage, then the
[Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and choose
**Memoir** under Style Settings → Borozdov Ember → Variant. The variant brings this
theme's palette, type and corners; its own layout, and its embedded font if it has one,
come with the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/memoir/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Memoir/`, then choose Borozdov Memoir under Settings →
Appearance → Themes.

## Font

Memoir Serif is embedded in `theme.css` as base64 WOFF2 under the SIL Open Font License 1.1
— see [`fonts/OFL.txt`](fonts/OFL.txt). It is a Latin and Cyrillic subset of Gentium Plus (©
2003–2023 SIL International), renamed because a modified copy may not use the original's
Reserved Font Name. One weight, for the title, the three largest headings, callout titles
and pull quotes.
